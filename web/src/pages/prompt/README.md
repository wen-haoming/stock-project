# Prompt 模板库

一个面向开发者的 Prompt 提示词模板集合，支持分类展示、预览、复制和暗黑模式。

## ✨ 功能特性

### 🎯 核心功能
- **分类展示**：按前端、后端、UI设计、编程规范等分类展示提示词
- **卡片布局**：响应式卡片布局，支持多种屏幕尺寸
- **预览功能**：点击预览按钮查看完整的提示词内容
- **一键复制**：快速复制提示词到剪贴板
- **AI推荐**：每个提示词都标注了推荐的AI工具

### 🌙 暗黑模式
- **主题切换**：支持亮色/暗色主题一键切换
- **持久化存储**：自动保存用户的主题偏好
- **平滑过渡**：主题切换时的动画效果
- **统一设计**：所有组件都支持暗黑模式

### 📱 响应式设计
- **移动端适配**：完美支持手机、平板等移动设备
- **桌面端优化**：大屏幕下的最佳显示效果
- **自适应布局**：根据屏幕尺寸自动调整卡片数量

## 🧩 组件架构

### 主页面组件 (index.jsx)
- 负责整体页面布局和状态管理
- 处理路由和分类过滤
- 管理暗黑模式状态
- 协调各个子组件的交互

### 子组件拆分
- **PromptCard**: 单个提示词卡片，负责显示和交互
- **PromptPreviewModal**: 预览模态框，显示完整内容
- **CategorySection**: 分类展示区域，管理卡片布局
- **DarkModeToggle**: 主题切换按钮，固定在右上角

## 🎨 样式系统

### 双主题支持
- **亮色主题**：浅色背景，深色文字
- **暗色主题**：深色背景，浅色文字
- **平滑过渡**：所有元素都有过渡动画

### 响应式断点
- `xs: 24` - 手机端：1列
- `sm: 12` - 平板端：2列
- `md: 8` - 小桌面：3列
- `lg: 6` - 大桌面：4列
- `xl: 4` - 超大屏：6列

## 📝 使用指南

### 添加新的提示词
1. 编辑 `config.js` 文件
2. 在对应分类的 `prompts` 数组中添加新的提示词对象
3. 保存文件，页面会自动更新

### 添加新的分类
1. 在 `config.js` 的 `categories` 数组中添加新分类
2. 在 `App.jsx` 中添加对应的路由配置
3. 在 `main.jsx` 中添加路由映射

### 自定义样式
1. 编辑 `styles.js` 文件
2. 修改对应的样式对象
3. 支持亮色和暗色两套样式配置

## 🔧 开发指南

### 组件开发规范
1. **单一职责**：每个组件只负责一个功能
2. **Props 传递**：统一使用 `currentStyles` 传递样式
3. **事件处理**：通过回调函数向上传递事件
4. **状态管理**：状态尽量提升到父组件

### 样式开发规范
1. **主题统一**：所有组件都支持暗黑模式
2. **响应式设计**：使用 Ant Design 的栅格系统
3. **动画效果**：添加适当的过渡动画
4. **可维护性**：样式集中管理，避免内联样式
