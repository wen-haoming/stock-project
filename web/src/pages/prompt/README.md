# Prompt 提示词模板集合

这是一个面向开发者的 prompt 提示词模板集合，提供了各种开发场景下的 AI 提示词模板。

## 功能特性

### 🎯 分类展示
- **前端开发**: React、Vue、CSS 等前端相关提示词
- **后端开发**: API 设计、数据库优化、微服务架构等
- **UI 设计**: 设计系统、用户流程、移动端设计等
- **编程规范**: 代码审查、重构建议、测试策略等

### 🎨 卡片式布局
- 紧凑的卡片设计，信息层次清晰
- 每个卡片包含标题、描述、标签、建议 AI 等信息
- 响应式布局，支持不同屏幕尺寸

### 🔍 交互功能
- **预览功能**: 点击预览按钮查看完整的提示词内容
- **复制功能**: 一键复制提示词到剪贴板
- **分类导航**: 通过左侧菜单快速切换分类

### 📝 可配置数据
- 所有提示词数据通过 `config.js` 文件配置
- 支持动态添加新的分类和提示词
- 便于维护和扩展

## 使用方法

### 1. 浏览提示词
- 在首页可以看到所有分类的提示词卡片
- 每个卡片显示提示词的基本信息和标签

### 2. 预览提示词
- 点击卡片上的"预览"按钮
- 在弹出的模态框中查看完整的提示词内容
- 可以了解提示词的使用场景和建议的 AI 工具

### 3. 复制使用
- 点击"复制"按钮将提示词复制到剪贴板
- 在模态框中也可以直接复制完整的提示词内容

### 4. 自定义配置
- 编辑 `config.js` 文件添加新的提示词
- 按照现有格式配置分类、标签、AI 推荐等信息

## 数据结构

每个提示词包含以下字段：

```javascript
{
  id: 'unique-id',           // 唯一标识
  title: '标题',             // 提示词标题
  description: '描述',       // 简短描述
  content: '完整内容',       // 提示词完整内容
  aiRecommend: ['AI1', 'AI2'], // 推荐的 AI 工具
  tags: ['标签1', '标签2'],   // 相关标签
  usage: '使用场景'          // 使用说明
}
```

## 技术栈

- **React 18**: 前端框架
- **Ant Design**: UI 组件库
- **Vite**: 构建工具
- **React Router**: 路由管理

## 开发说明

### 添加新提示词
1. 在 `config.js` 中找到对应的分类
2. 在 `prompts` 数组中添加新的提示词对象
3. 按照现有格式填写所有必要字段

### 添加新分类
1. 在 `config.js` 的 `categories` 数组中添加新分类
2. 配置分类的图标、颜色和提示词列表
3. 在 `App.jsx` 中添加对应的路由配置

### 自定义样式
- 主要样式在 `index.jsx` 中通过内联样式定义
- 可以根据需要调整卡片布局、颜色主题等

## 扩展功能

可以考虑添加的功能：
- 搜索功能：根据关键词搜索提示词
- 收藏功能：收藏常用的提示词
- 使用统计：记录提示词的使用次数
- 用户反馈：收集用户对提示词的评价
- 导入导出：支持批量导入导出提示词
